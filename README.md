# PARKINGNOW Landing Page

Landing page oficial de **PARKINGNOW**, una solución de estacionamiento inteligente que conecta conductores y propietarios mediante tecnología IoT en tiempo real.

## Descripción

Este proyecto presenta una experiencia web moderna para comunicar la propuesta de valor de PARKINGNOW:
- Reserva de estacionamiento en segundos.
- Visualización de beneficios para conductores y propietarios.
- Enfoque en movilidad urbana, reducción de tráfico y eficiencia operativa.

## Características principales

- Diseño responsive para desktop, laptop, tablet y móvil (Android/iOS).
- Navegación superior con desplazamiento suave a secciones.
- Soporte de idioma **ES / EN** para toda la página.
- Estructura visual orientada a producto tecnológico.
- SEO on-page reforzado (metadatos sociales y estructurados).

## Estructura del proyecto

- `index.html`: Estructura y contenido de la landing.
- `styles.css`: Estilos personalizados.
- `script.js`: Interacciones de idioma y navegación.
- `assets/`: Recursos visuales (favicon, imágenes auxiliares).

## Ejecución local

No requiere build.

1. Clona el repositorio.
2. Abre `index.html` directamente en el navegador.

## Despliegue

Compatible con **GitHub Pages**.

Pasos sugeridos:
1. Subir el proyecto a la rama `main`.
2. Activar GitHub Pages desde `Settings > Pages`.
3. Seleccionar la carpeta raíz (`/root`).

## Público objetivo

- Conductores que buscan estacionar de forma rápida y confiable.
- Propietarios que desean monetizar espacios de estacionamiento.
- Equipos interesados en soluciones de movilidad inteligente.
