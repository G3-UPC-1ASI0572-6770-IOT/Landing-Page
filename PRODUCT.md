# Product

## Register

brand

## Users

Two audiences:
- **Drivers in Lima** looking for guaranteed parking before arriving. Context: driving, time-pressured, frustrated by wasted trips. Job: confirm a spot is real, reserve it, drive straight there.
- **Parking lot owners** wanting to modernize. Context: currently managing manually with pen and paper. Job: attract more reservations and get real-time occupancy without additional staff.

## Product Purpose

ParkingNow is an IoT-verified smart parking platform connecting drivers with parking operators in Lima using real-time ultrasonic sensor data. Success = a driver who navigated straight to a guaranteed spot without circling, and an owner who tracked their lot from a dashboard instead of a clipboard.

Academic project for UPC course 1ASI0572, 2026, by Code Mondoguito.

## Brand Personality

Smart · Modern · Urban. Engineering-credible but city-product accessible. The confidence of a data platform with the directness of a mobility app. Not technical theater — the IoT is real and the copy is honest about what it is.

## Anti-references

- Generic SaaS landing (cream bg, identical rounded cards, eyebrows on every section, warm-neutral palette)
- Uber/Grab clones (map-dark-blue, rideshare aesthetic)
- Government/municipal portals (heavy, institutional, permit-office feel)
- Startup hype (gradient everything, "revolutionize" copy, emoji-heavy)

## Design Principles

1. **Show the system** — the IoT architecture is the differentiator; make it visible, not just described.
2. **Honest before impressive** — the product is an MVP with 2 live spaces. Don't oversell. Transparency builds trust.
3. **Speed signals credibility** — a fast page load = a fast product. Performance is brand.
4. **One signal per section** — don't stack every visual treatment at once. Pick the right one for the content.
5. **City product, not startup theater** — urban, direct, no filler. Lima is the context; name it.

## Accessibility & Inclusion

Best effort. Fix obvious issues: contrast, keyboard navigation, meaningful alt text, screen reader labels on interactive elements. No formal WCAG audit required for academic delivery.
